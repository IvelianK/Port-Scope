# Code of Conduct

PortScope's issues, pull requests and discussions are for building a useful defensive security tool. Everyone taking part is expected to:

- Be respectful and constructive, whatever someone's experience level, background or identity.
- Critique code and ideas, not people.
- Assume good faith, and ask before assuming the worst.
- Keep vulnerability details out of public threads. Report them privately as described in [SECURITY.md](SECURITY.md).
- Use PortScope and anything learned here only on systems and networks you are authorized to assess.

Not acceptable: harassment, insults, discriminatory language, sexualized content, doxxing or sharing other people's private data (including IP addresses from scan reports), and encouraging attacks on third parties.

## Enforcement

Report problems to the maintainer through a [private security advisory](https://github.com/IvelianK/Port-Scope/security/advisories/new) or a private GitHub message to [@IvelianK](https://github.com/IvelianK). Reports are handled confidentially. The maintainer may edit or remove content and restrict or ban participants who break these rules.
